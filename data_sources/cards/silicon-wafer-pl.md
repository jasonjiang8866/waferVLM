# Silicon wafer photoluminescence and SEM

- Primary source: https://zenodo.org/records/19603335.
- Title: *Dataset for “Non-disruptive HF pretreatment to enhance defect visibility
  in silicon wafer manufacturing via photoluminescence imaging”*.
- Creator list and attribution: [provider metadata](../metadata/zenodo-19603335.json).
- License: **CC-BY-4.0**, verified in the provider record.
- **21 files, 38,583,583 bytes**: nine 1024 × 1024, 32-bit RAW PL images,
  one SEM PNG, and eleven CSV measurement files. Each file has a pinned publisher
  MD5 and exact size in [catalog.json](../catalog.json).
- These are experiment/figure data covering process and imaging conditions,
  laser grooves and stacking faults. They are not 21 independently labeled wafers.
- Proposed use: condition comparisons, line profiles, quantitative image changes,
  microscopy QA. Confirm RAW numeric encoding/endianness before visualizing it;
  do not infer this only from the file size.
- Global Volume: **not imported**. The source SEM PNG can be kept in Git as a
  small, attributed example; full files use the same download/import recipe.

Citation: use the creator list and associated paper identifiers in the provider
record; dataset DOI https://doi.org/10.5281/zenodo.19603335.
