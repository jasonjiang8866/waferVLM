# WM-811K — existing project dataset

- Original source lead: https://mirlab.org/dataSet/public/ (unavailable in this check).
- Existing pinned mirror: https://www.kaggle.com/datasets/qingyi/wm811k-wafer-map.
- Authoritative project acquisition details: [data audit](../../docs/data-audit.md),
  [machine-readable evidence](../../docs/evidence/wm811k-lot17.json),
  [existing downloader](../../scripts/prepare_public_data.py).
- 811,457 rows, including 25,519 in the eight target defect classes. After the
  project's conflicting-label quarantine and exact deduplication there are
  25,422 unique target maps before sampling. Current train/validation/test is
  **790/160/160**, so the small training set is partly a deliberate cap.
- ZIP 156,686,283 bytes; pickle 2,095,505,977 bytes. Identity hashes are already
  pinned by the existing recipe. No second download in this collection change.
- Mirror declares CC0; original publisher's terms were not independently
  confirmed. This folder does not upgrade that statement to an original license.
- Keep pickle loading behind the existing explicit trust opt-in. Preserve the
  reserved holdout and lot-group boundaries; broader training needs a new split
  protocol, not a silent increase in the existing benchmark caps.

Next project: larger train subsets, normal/unknown handling, semi-supervised
learning. Unlabeled rows are not automatically labeled normal.
